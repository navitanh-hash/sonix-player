# Changelog

## v1.1.0

### Automatic animation

- Added alternating slider animations.
- Increased demonstration displacement to 94 px.
- Added two damped spring rebounds.
- Removed decorative outlines.

### Interactive gestures

- Added seamless takeover of animated knobs.
- Preserved the current position when grabbed.
- Kept the other slider's animation independent.
- Added double rebound after incomplete gestures.
- Added adaptive rebound amplitude.

### Safety and appearance

- Required an intentional drag and explicit release.
- Prevented power actions on lost touch contact.
- Preserved original power management functions.
- Improved instruction text alignment.

### Testing

- Successfully tested in the SDL2 host simulator.
- Successfully tested on a physical HiBy R1.

### Distribution

- Source code and reusable Git patch.
- Reference base commit.
- Recorded simulator demonstration.
- Build and integration instructions.
- Complete firmware available upon request.
